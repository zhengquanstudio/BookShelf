## 1. 本次目标（1.1.6 交付口径）

版本号 1.1.5 → **1.1.6**，一次改完下列全部，允许分步提交，但最终必须一起发版。

### A. 品牌与安装（用户明确要求）

1. 左上角字标：`QLabel("BS")` 方块取消，改「图标（书字形）+ 中文名 **书格** + 副标 **BookShelf**」两行组合，中文主、英文 9.5px 灰度副标；主窗口标题仍用 `config.APP_NAME_CN`。
2. 安装器 `installer\BookShelf.iss`：
   - `DefaultDirName={autopf}\BookShelf`（即 `C:\Program Files\BookShelf`）
   - `PrivilegesRequired=admin`
   - 新增 `[Run]`：`Filename: "{app}\BookShelf.exe"; Description: "启动 书格 BookShelf"; Flags: nowait postinstall skipifsilent`
   - `[Code]` 里检测旧目录 `{localappdata}\Programs\BookShelf` 与用户自定义目录，装完提示"旧目录可手动删除"，不要自动删用户文件。
3. EXE 属性 `FileDescription` / `ProductName` 保持「书格 BookShelf」（已改，打包验证即可）。

### B. 书库主界面（对应 v4 原型）

4. 顶栏压成单行 52px：品牌区 | 分段动作组「扫描新书 / 书库 / 识别元数据 / 整理预览」 | 主按钮「执行整理」 | 搜索框 | 列表/网格切换 | 齿轮。删掉工具条右侧重复的「设置」按钮，菜单里的设置保留。
5. 左导航 236px，四组「书库 / 分类 / 阅读 / 其他」，条目带计数与左侧 3px 选中条。
6. 表格：加封面缩略图 28×38、阅读进度条、文件大小、添加时间；所有列头可排序；ISBN 列宽 132px 且 hover 显示全文；底部改「已显示 N / 共 M 本 · 加载更多」。
7. 详情面板 384px：封面渐变占位；「数据文件 / 归档路径」两个独立 pathbox，新路径用 accent 色；简介 4 行截断可展开；动作顺序 阅读(主) / 编辑元数据 / 重新检索 / 打开文件夹 / 加入收藏。
8. 批量条：多选浮出「已选 N 本 · 批量归档 / 移动到… / 重新识别 / 导出清单」。
9. 新增「我的书架 / 阅读统计 / 笔记与高亮」三页（原型里的网格卡片、4 指标+柱状、四类筛选）。

### C. 设置页（主界面）

10. 左栏 6 分区：外观与主题 / 阅读 / 书库与整理 / 识别来源 / 字体 / 关于；右栏行式控件。
11. 新增 `app/ui/theme.py` 统一 token：3 套底色（纸白/灰调/夜间）+ 5 套强调色（蓝/绿/紫/琥珀/玫红），写入 settings 键 `ui_theme` / `ui_accent`，切换即时生效不重启。

### D. 阅读界面（对应 v3 原型，核心）

12. **固定书页**（这是必须修的 bug）：
    - 阅读容器 `SizePolicy` 改 Expanding，外层 `QVBoxLayout` 用 `addWidget(view, 1)`，禁止随内容增高；
    - `reader.css` 阅读页 `height:100%; overflow:hidden; display:flex; flex-direction:column`，正文层 `flex:1; min-height:0; overflow:hidden`；
    - `reader.js` 分页按**容器可视高度**切，不让文档自然长高；正文底部加 7% 渐隐；
    - 字号 / 行距 / 页边距 / 窗口尺寸变化 → debounce 80ms 重新分页，用"当前页首段 textNode + offset"作锚点回位（允许 ±1 页）；
    - 底栏总页数**动态**，不许缓存。
    - 参照 Readest 的 `--available-height` + `body.paginated-mode` + `maxColumnCount` 思路，自行实现，不抄代码。
13. 封面卡：56×78 书封（书脊阴影 + 内描边 + 外投影 + 右上朱红印章）+ 书名 14.5px + 作者/出版社 + 「在读」+ 3px 进度条 + 百分比 + 圆 i。
14. 顶栏 46px：侧栏开关 + 章节名 + 书名（灰）+ 右侧 5 图标；**修掉把"封面"当章节名的 bug**：章节标题取 location.title，取不到显示书名。
15. 左栏 288px，目录三页签；条目右对齐页码、当前章整行浅底 + 3px 竖条 + 「当前位置」标签。
16. 底栏 38px：24 段墨点进度条（自绘、可点击 seek）+ `22 / 318` + 剩余分钟/页 + 时钟 + 电池 + 页码输入。删掉原来重复的 `1/324` 与独立页码框。
17. 高亮改「文字下 38% 荧光笔」效果，4～5 色可配；选中浮条：高亮 / 写批注 / 复制 / 朗读。
18. 设置弹窗 `app/ui/dialogs/reader_prefs_dialog.py`：居中 660px、圆角 18、遮罩模糊、Esc/点遮罩/右上 × 均可关；顶部图标页签 主题/字体/布局/阅读/手势，每页分组卡片 + 步进器/开关；页面卡里必须有「页宽固定（文字重排不拉长书页）」开关。
19. 8 套纸面 token（默认/素雅/旧韵/青草/樱粉/天青/日晖/夜间），浅色/深色模式；「分栏」文案统一 **单页 / 双页摊开**，同时修 `reader.js` 的 `max-column-count` 语义（R2 遗留）。
