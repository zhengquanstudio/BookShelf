## 二、高亮 4 色的实现细节（第 2 条）

- 语义名：`blue / amber / green / pink`，prefs 键 `reader_highlight_color`，默认 `blue`。
- 浅色纸面直接用上面的 hex；夜间纸面自动降明度，在 `reader.css` 里按纸面覆盖：

```css
html[data-paper="night"]{
  --hl-blue:#2C4257; --hl-amber:#4A3B22; --hl-green:#31412A; --hl-pink:#45303A;
  --hl-ink:#CFE3F3;
}
```

- 渲染仍是「文字下 38% 荧光笔」：`background:linear-gradient(180deg,transparent 56%,var(--hl) 56%,var(--hl) 94%,transparent 94%)`。
- 设置弹窗色板 4 个圆点；写入时只存语义名，不存 hex，换主题不用迁移数据。

## 三、theme.py 结构（第 3 条）

单一来源，两套域，禁止在多处重复 hex：

```python
# app/ui/theme.py
CHROME = {            # 主界面：3 底色 × 5 强调色 → 键 ui_theme / ui_accent
  "paper": {...}, "gray": {...}, "night": {...},
}
ACCENTS = {"blue": "#3B6EF5", "green": "#2F9E6E", "purple": "#7A63D6",
           "amber": "#C88A2A", "rose": "#C95F7A"}

READER_PAPERS = {     # 阅读器 8 纸面 → 键 reader_paper_mode / reader_paper_light
  "paper":   {"name":"默认", "bg":"#F3EDE1","sheet":"#FBF7EF","ink":"#33302A", ...},
  "plain":   {"name":"素雅", ...},   # 灰
  "old":     {"name":"旧韵", ...},   # 米黄
  "grass":   {"name":"青草", ...},
  "sakura":  {"name":"樱粉", ...},
  "sky":     {"name":"天青", ...},
  "sunset":  {"name":"日晖", ...},
  "night":   {"name":"夜间", ...},
}
```

- Qt 侧：`build_qss(theme, accent)` 生成样式表；
- Web 侧：启动时把当前纸面的 token 以 `:root{--bg:…;--sheet:…;…}` 注入 reader.css（用占位 `/*%PAPER_TOKENS%*/` 或 `QWebChannel` 下发），**reader.css 里不再写死色值**；
- 色值来源与命名：v4 原型（chrome）、v3 原型（papers），代码 id 用上表英文，中文名做显示名；
- 断言：`tests/test_theme_tokens.py` 检查 8 纸面必须齐 `bg/sheet/ink/ink_soft/muted/line/line2/accent/accent_soft/accent_ink/hl`，少一个即红。

## 五、主题联动（第 7 条）

三个键，互不覆盖：

| 键 | 取值 | 作用 |
|---|---|---|
| `ui_theme` | paper / gray / night | 主界面 chrome |
| `reader_paper_mode` | **auto / light / dark**（默认 auto） | 阅读器纸面策略 |
| `reader_paper_light` | paper/plain/old/grass/sakura/sky/sunset | 记忆"浅色时用哪张纸" |

规则：

- `auto`：`ui_theme == night` → 阅读器用 `night`；否则用 `reader_paper_light`。
- `light` / `dark`：手动锁定，忽略界面主题。
- 在阅读器里选浅色纸面 → 只写 `reader_paper_light`；选夜间 → 若当前 mode=auto 则写 `reader_paper_light` 不动，只临时切 night 并提示"已切夜间，可在设置里改回跟随界面"。
- 任何情况下不互相覆盖对方的键。

## 六、安装器旧目录检测（第 8 条）

```ini
[Code]
function GetPreviousInstallDir(): String;
begin
  Result := '';
  RegQueryStringValue(HKCU,
    'Software\Microsoft\Windows\CurrentVersion\Uninstall\BookShelf',
    'InstallLocation', Result);
end;
```

- (a) 固定查 `{localappdata}\Programs\BookShelf` 是否存在；
- (b) 注册表 `InstallLocation` 与本次 `{app}` 不同 → 记录为"旧目录"；
- 完成页提示：「已安装到 C:\Program Files\BookShelf。旧版本目录 … 可手动删除（不影响书目与设置）」；
- **绝不自动删除、绝不静默迁移**；数据仍在 `%APPDATA%\BookShelf`。
- 卸载项 `InstallLocation` 由 Inno 自动写新路径，不必额外处理。
