# BookShelf 安装与覆盖安装验收清单

验收版本：1.1.3  
安装包：`release\BookShelf-Setup-1.1.3.exe`  
校验文件：`release\checksums.txt`

## 验收准备

- 使用专用 Windows 验收账户或虚拟机；电子书、书库、配置与备份均使用临时测试数据。
- 记录安装包的 SHA256，并与 `checksums.txt` 对照。
- 准备 20 本测试电子书、一个非默认程序安装目录，以及用于覆盖安装的新版本安装包。
- 覆盖安装的两个安装包必须保持相同 `AppId`，且后一个版本号高于前一个。
- 如已有 BookShelf 数据，先停止程序并另行备份；不得在唯一真实书库上直接做卸载测试。

## 十步清单

- [ ] 1. 在全新环境启动安装包，选择一个非默认安装目录并完成安装；确认文件实际写入所选目录。
- [ ] 2. 确认开始菜单图标正确；勾选桌面任务时，确认桌面图标与目标路径正确。
- [ ] 3. 通过“打开方式”选择 BookShelf 后双击 `.epub`；程序已运行时再次打开另一本书，确认路径转发给原实例且不出现第二个主程序。
- [ ] 4. 创建测试书库并扫描 20 本电子书；确认数量、书名、作者和格式显示正确。
- [ ] 5. 修改一项设置并产生阅读进度，然后正常关闭程序。
- [ ] 6. 直接运行新版本安装包覆盖安装；确认进入升级流程，而不是提示无法安装或生成另一份独立应用。
- [ ] 7. 确认覆盖安装沿用第一次选择的目录，没有恢复为默认目录。
- [ ] 8. 启动覆盖安装后的程序；确认书库数据、设置与阅读进度全部保留。
- [ ] 9. 正常关闭程序并卸载；确认程序目录已清空，而 `%APPDATA%\BookShelf` 及其中的数据库、设置和阅读进度仍保留。
- [ ] 10. 重新安装并启动；确认程序自动识别 `%APPDATA%\BookShelf` 中原有数据，无需重新建库。
