# 书格 1.1.6 · 阅读界面 v3：固定书页 + Readest 式设置面板（给 TRAE）

> 2026-11-28 · 配套原型 `书格-UI原型-v3/书格-阅读界面原型-v3-1.1.6.html`
> 现象：字号调大后，「书页」被往下拉长，而不是页高固定、文字重新排版。

---

## 一、这个 bug 的根因

原型 v2 里 `.sheet` 用的是**内容自适应高度**（只有 `width`，高度由文字撑开）：

```css
.sheet{width:700px; padding:44px 56px}   /* 没有 height */
```

字号一变大 → 行数变多 → 内容把容器撑高 → 页面"长长地垂下去"。
本机程序里同理：`QWebEngineView` 的阅读容器如果设成 `height:auto / SizePolicy:Preferred`，字体放大时容器会跟着长。

**Readest 的做法**：页面高度固定 = 视口高度，正文区用分栏/分页容器（CSS `columns` + 固定 `height`），字号、行距、页边距任一变化 → **重新分页**，总页数变、当前页位置尽量保持，页框尺寸一动不动。

---

## 二、v3 的修法（原型已按此实现，可直接对照）

```css
.reader{height:100vh; display:grid; grid-template-columns:288px 1fr; grid-template-rows:100vh; overflow:hidden}
.stage {flex:1; min-height:0}                       /* 必须给 min-height:0 */
.sheet {width:700px; height:100%;                   /* ← 页高固定，不再由内容决定 */
        display:flex; flex-direction:column; overflow:hidden;
        padding:42px 54px 46px}
.prose {flex:1; min-height:0; overflow:hidden;       /* ← 文字只在这里流，超出即分页 */
        font-size:var(--fs); line-height:var(--lh);
        mask-image:linear-gradient(180deg,#000 93%,transparent 100%)}
```

验证（已渲染核对）：17px 时 `22 / 318`；调到 26px 后**书页高度完全不变**，总页数变 `22 / 486`，进度 7% → 5%，正文底部渐隐截断——这才是"只改字号、不改页框"。

---

## 三、设置面板对齐 Readest

Readest 那个弹窗结构是：**顶部一排图标页签（主题 / 布局 / 手势 / 字体 / 语音…）+ 每个页签里是分组卡片 + 右侧步进器/开关**，中间居中浮层、背景模糊。

v3 已按这个结构做：居中 660px、`backdrop-filter: blur(2px)`、圆角 18px，5 个图标页签 `主题 / 字体 / 布局 / 阅读 / 手势`，每页分组卡片：

| 页签 | 卡片内容 |
|---|---|
| 主题 | 主题模式（跟随系统 / 浅色 / 深色）、深色下图片反色、透明图片背景、覆盖书籍颜色；主题颜色 8 张卡（默认/素雅/旧韵/青草/樱粉/天青/日晖/夜间）；高亮颜色 4 色 |
| 字体 | 覆盖书籍字体；字号（默认字号 17 / 最小字号 8 / 正文字重 400）；首选字体（类别、衬线、无衬线、等宽、忽略出版方字体）；底部预览卡 |
| 布局 | 覆盖版面布局；排版模式 4 个图标；段落卡（使用书籍排版、段间距、行间距、字间距、首行缩进、两端对齐、断字）；页面卡（上/下/左/右边距 + 「页宽固定」） |
| 阅读 | 翻页/滚动、单页/双页摊开、自动翻页、段滚；状态栏（剩余时间、时钟、电池、点击翻页区）；辅助（顶部遮罩、选中朗读、阅读尺） |
| 手势 | 单击显隐工具栏、双击缩放、长按选词、左右滑动翻页 |

关键点：**「页宽固定（文字重排不拉长书页）」这条开关就放在布局页的页面卡里**，把这次修的行为直接暴露给用户。

## 四、给 TRAE 的代码步骤（接 T9–T15）

```
T16 固定页框（核心）
    1) reader_container.py：阅读容器 SizePolicy 改 Expanding/Expanding，高度取 webview 高度，
       不再 setMinimumHeight 随内容增长；外层用 QVBoxLayout 且 addWidget(webview, 1)。
    2) reader.css：.page / #view 设 height:100%; overflow:hidden; display:flex;
       正文容器设 flex:1; min-height:0; overflow:hidden。
    3) reader.js：分页改为「按容器可视高度分页」——每次 layout 后取 clientHeight，
       用累计行高把段落切到第 N 页，而不是让文档自然长高。
    4) 监听 resize / 字号 / 行距 / 页边距变化 → 重新分页（debounce 80ms），
       记住当前页首个段落节点（textNode + offset）作为锚点，重排后回到该锚点。
T17 字号/行距设置打通
    prefs 键统一：reader_font_size / reader_line_height / reader_margin（默认 17 / 1.95 / 54），
    Aa 面板步进器直接写库并触发 T16 的重排；底部总页数随之更新（不要缓存旧总页数）。
T18 设置弹窗
    新建 app/ui/dialogs/reader_prefs_dialog.py：
    QDialog（无边框、圆角 18、居中、半透明遮罩），顶部 QToolBar 样式的图标页签，
    内容用 QScrollArea + 分组 QFrame（卡片背景 #f7f3ea、圆角 12），
    行控件统一 左标签 + 右控件（开关用自绘 Toggle，步进器用 − 值 ＋）。
    页签与卡片严格按第三节表格；主题 8 卡用 QListWidget(IconMode) 或自绘 QFrame 网格。
T19 主题与高亮
    theme.py 扩到 8 套纸面 token（默认/素雅/旧韵/青草/樱粉/天青/日晖/夜间），
    高亮色 4 选 1 存 prefs；切换即时生效，不重启。
```

**验收命令**

```powershell
.venv\Scripts\python.exe -m pytest tests -q
```

**人工验收（必须逐条过）**

1. 字号 17 → 26：书页矩形（宽高）一像素不变，只文字变大、总页数增加；
2. 调到 26 后滚到第 30 页，再调回 17，仍停在原段落附近（允许 ±1 页）；
3. 拉窗口边框改变高度：页框跟随窗口，文字重新分页，不出现内部滚动条与外层双滚动；
4. 主题切夜间后，8 套纸面里只有夜间变暗，返回浅色可复位；
5. 设置弹窗 Esc / 点遮罩 / 右上 × 三种方式都能关。

## 五、与 v2 的差异清单

| 项 | v2 | v3 |
|---|---|---|
| 书页高度 | 内容撑高（bug） | 固定 = 视口高，超出渐隐并分页 |
| 页数 | 恒 318 | 随字号/行距重算（17px=318，26px≈486） |
| 设置面板 | 右侧 330px 抽屉 | 居中 660px 弹窗 + 图标页签 + 分组卡片 |
| 设置项 | 平铺 20 行 | 分 5 页签 25+ 项，含「页宽固定」开关 |
| 主题 | 4 套纸面 | 8 套纸面 + 浅/深模式 |
| 高亮色 | 5 色 | 4 色（与 Readest 对齐），圆形色点选择 |
| 底栏 | 墨点进度 + 页码 + 剩余 + 时钟 | 同左，页数改为动态 |
