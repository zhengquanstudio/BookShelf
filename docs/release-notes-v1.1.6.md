# 书格 1.1.6

本次更新完成书库与阅读器 UI 改版，并补齐“我的书架 / 阅读统计 / 笔记”三个页面。

## 新增

- **我的书架**：封面网格、阅读进度、搜索与排序；只显示有阅读记录或已收藏的书，空书架可一键去书库。
- **阅读统计**：累计与本月阅读时长、已读数量、连续阅读天数、近 6 个月图表、最近 10 次阅读记录。
- **笔记**：笔记 / 高亮 / 书签分类浏览，支持搜索正文与想法、按书折叠分组、删除，以及点击跳回正文位置。
- **书库网格视图**：表格与网格随时切换，重启后仍记住上次选择。
- **阅读设置弹窗**：主题、字体、布局、阅读、手势与其他 6 个页签，8 套纸面主题与 4 色高亮，修改即时生效。

## 变更

- 书库品牌字标、52px 顶栏、236px 导航、八列排序表格、详情面板与批量操作条全面更新。
- 阅读器更新封面卡、目录当前位置、46px 顶栏、38px 墨点进度底栏、固定页框与选中浮条。
- 字号、行距、页边距默认值与范围对齐新版原型。
- 安装器默认安装到 `C:\Program Files\BookShelf`，需要管理员权限；完成页可勾选“启动 书格 BookShelf”。

## 升级说明

- 书库数据库、书籍文件、阅读进度、书签与高亮沿用现有数据，不需要重新扫描。
- 安装到旧目录时只会提示，不会主动删除旧文件。

完整 SHA256 校验值见 Release 附件中的 `checksums.txt`。
