## 二、三处口径以代码为准，不改代码，只登记（避免文档再打架）

1. **纸面 key 用代码里的八个**：`light(纸白) / sepia(米黄) / gray(灰白) / grass(草绿) / cherry(樱粉) / sky(天青) / sunset(日晖) / dark(夜读)`。决议文里写的 `paper/plain/old/sakura/night` 是设计稿别名，代码里 `_ALIASES` 已兼容 `paper→light / night→dark`，**后续文档一律写代码名**。
2. **主题三档落在 `reader.theme` + `reader.mode`**（不是 `reader_paper_mode/reader_paper_light`）。`mode=auto` 的实际行为是**跟随系统深浅**（`palette_for(..., system_dark=_system_dark())`），与我原决议的"跟着界面夜间"不同——**以代码为准，保留"跟随系统"，不改成跟界面联动**。界面夜间只影响 chrome，不影响纸面，两者各存各的键，这点与决议一致。
3. **安装器旧目录检测只做了 (a)**：`{localappdata}\Programs\BookShelf` 的 `DirExists` 提示。注册表 `InstallLocation` 分支不做（可选项，收益低、代码长），保持现状。

## 三、T20–T22：补齐三个新页（必做，做完才发版）

总体约束：
- 视觉一律对齐 `docs\书格-UI原型-v4-1.1.6.html` 对应区块；不改数据层、不动 S/F/D 段。
- 每页新建独立文件 `app\ui\pages\shelf_page.py` / `stats_page.py` / `notes_page.py`，在 `main_window.py` 的 `content_stack` 里注册，`_on_nav()` 增加三个分支（`shelf/stats/notes`），并让底部"状态统计"条在该页隐藏。
- 空态统一：灰底空图表骨架 + 「暂无数据」+ 一句引导 + 一个按钮（按钮要真的能跳转，不能只弹提示）。
- 每步单独提交，`pytest` 全绿后才提交下一条。

### T20 书架页（网格视图）
- 交付 `shelf_page.py`：`QListView` + 自定义 delegate，卡片 = 封面 132×176（无封面时用书名首字占位）+ 书名 2 行省略 + 作者 1 行 + 底部进度细条（`read_state.percent`）+ 右上角圆 i（复用 `BookDetailOverlay.show_for(book_id)`）。
- 数据源复用现有 `BookTableModel`，**不要另建一套查询**；网格列数按宽度自适应（`viewport.width() // (132+24)`，最少 3 列）。
- 书架页顶部保留搜索框与排序下拉，与书库页共用筛选状态（切页不重置搜索词）。
- 「我的书架」只列 `read_state` 有记录或 `books.favorite=1` 的书；一本没读时走空态「书架还空着，去书库挑一本」+「去书库」按钮（跳 `all`）。
- 验收：`tests/test_shelf_page.py` —— ① 有书时卡片数量 = 查询条数；② 无封面不崩、显示首字；③ 空态文案出现且按钮可点（离屏，`web_enabled=False`）。

### T21 统计页
- 交付 `stats_page.py`：4 张指标卡（累计阅读时长 / 本月时长 / 已读书籍数 / 连续阅读天数）+ 近 6 个月柱状图（`QPainter` 自绘，不引第三方图表库）+ 最近 10 次阅读记录列表（书名、日期、时长、页数）。
- 数据全部来自 `app\db\repositories\reading_repo.py` 与 `books/read_state`；跨天连续天数按 `substr(started_at,1,10)` 去重逆推，**同一实现只写一处**（放进 `reading_repo`，UI 只取结果）。
- 时长 <60s 显示「不足 1 分钟」，不显示 0.0 小时；数字用等宽字体（`Literata` 数字或 `Consolas`）。
- 空态：4 张卡显示 `0`、柱状图保留坐标轴与灰色空槽（不画假柱），下方「暂无阅读记录，去读几本书吧」+「去书架」。
- 验收：`tests/test_reading_stats.py` —— ① 空库返回 0 不抛异常；② 构造 3 天连续 session 得连续天数 3；③ 跨月聚合正确。

### T22 笔记页
- 交付 `notes_page.py`：三段式（笔记 / 高亮 / 书签）用顶部 seg 切换 + 搜索框 + 按书分组的折叠列表；每条右侧显示 4 色圆点（`bookmarks.color`，取语义名渲染 `HIGHLIGHT_LIGHT/NIGHT`）。
- 点击条目 → 打开该书并跳到 `bookmarks.locator`（复用现有跳转接口，禁止新写一套位置解析）。
- 删除单条走现有 `reading_repo.delete_bookmark`，删完即时刷新并 toast。
- 空态：三页签各自文案——「还没有笔记」/「还没有高亮，选中正文即可标记」/「还没有书签，按 Ctrl+D 添加」。
- 验收：`tests/test_notes_page.py` —— ① 三类过滤互不串；② 搜索命中 text 与 note；③ 删除后条数-1 且 DB 同步。

### T23 表格网格视图接线（顺带）
