# 书格 BookShelf 1.1.4

Windows 本地电子书管理与阅读器 · 首个公开版本。

## 下载

- **安装包**：`BookShelf-Setup-1.1.4.exe`（约 118 MB，含 8 套内嵌中英文字体）
- **SHA256**：`e9f5c32e1759b36764195d684a49bbbe8fb1768e0c71b2892b54a0da759abd64`
- 校验命令（PowerShell）：`Get-FileHash .\BookShelf-Setup-1.1.4.exe -Algorithm SHA256`

## 安装说明

1. 双击安装包，默认装到 `%LOCALAPPDATA%\Programs\BookShelf`（安装时可改）；
2. 书库、设置、阅读进度保存在 `%APPDATA%\BookShelf`，**卸载不会删除**，重装后书目自动恢复；
3. 首次启动扫描书库目录即可，扫描不会移动你原有的文件（整理动作需你确认后才执行）；
4. 需要 Windows 10 1809 及以上 / Windows 11，64 位。

## 本版内容

### 新增

- 图书识别接豆瓣读书、Crossref、孔夫子旧书网三个检索源；豆瓣按 ISBN 直达并强校验页面 ISBN。
- 扫描阶段新增文件名解析（L0）：可从 `作者 - 书名 (年份)`、`《书名》作者`、`[作者] 书名`、`书名(第N卷)` 中提取书名、作者、年份、卷号与 ISBN。
- 内嵌元数据补强：EPUB 多作者分隔与 `urn:isbn:` 形式；PDF 标题优先取书签第一层并抽取 DOI。
- 命名模板新增 `{丛书}` `{年份}` `{出版社}` `{ISBN}` `{作者全}` 变量。
- 整理流程新增「只重命名」：原目录改名、不跨目录，冲突自动追加 (2)/(3)，支持批次撤销。
- 候选结果卡支持封面缩略图、来源徽标、匹配依据与字段级勾选。
- 阅读器界面与设置改版：顶栏/侧栏/底栏重排，目录三栏并显示页码，底栏进度、时钟与字号步进。
- 内置 8 套字体（霞鹜文楷、思源宋体、霞鹜新宋、Noto Sans SC、Literata、Source Serif 4、EB Garamond、Inter），安装后直接可用，无需系统装字体。

### 变更

- 匹配度改为「先否决再打分」：ISBN 冲突、缺 ISBN 且书名相似度不足直接丢弃。
- 候选应用改为字段级合并，只写勾选字段。
- 默认文件模板改为 `{作者} - {书名}{卷号} ({年份}).{扩展名}`。
- 数据库升级到 v4（新增 `source_path` 记录重命名批次原路径），启动自动迁移。

### 已知问题

- 双页「摊开」模式尚未落地，当前设置里的展示方式仍是单页分栏语义，下个版本修正。
- 阅读界面顶栏未显示封面缩略图与作者，正在按原型重排。
