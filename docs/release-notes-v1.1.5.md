# 书格 1.1.5

本次更新集中在阅读器：新增书籍详情浮层与元数据编辑，并支持 EPUB 内嵌 OPF 回写。

## 新增

- 阅读器顶栏改版：封面、书名/作者、搜索、书签、阅读设置、笔记、固定侧栏与更多菜单；顶栏和底栏同步自动隐藏，正文不跳动，光标移到窗口上/下边缘时唤出。
- 404px 书籍详情浮层：封面、作者与出版信息、标签、阅读状态、语言/页数/ISBN/系列/进度、数据文件与归档路径、可展开简介。
- 编辑元数据：书名、作者、出版社、出版日期、页数、语言、ISBN、系列、标签；保存前校验书名、ISBN 与页数。
- 保存后按当前命名模板归档；EPUB 同时写回内嵌 OPF 的标题、作者、出版社、日期、语言、标识与页数，写入前生成 `.bak` 备份并原子替换。
- 详情浮层新增“恢复内嵌元数据”和“打开文件夹”，并提供带预览确认的“按命名模板重算”。

## 变更

- 收藏入口移入阅读器“更多”菜单，详情中的喜爱标记与书架同步刷新。
- PDF/MOBI/AZW3 不支持 OPF 回写，只更新书库与文件名，界面会明确提示。
- 归档移动记录统一记为 `move`。

## 修复

- 详情浮层、侧栏或搜索框打开时，顶栏与底栏不再自动隐藏。
- 归档移动失败时会回滚元数据、标签与文件路径，并显示具体原因。

完整校验值见 Release 附件中的 `checksums.txt`。
