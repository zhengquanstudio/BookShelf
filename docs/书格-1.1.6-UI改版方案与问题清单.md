## 三、问题清单（看完截图 + 代码确认）

### 3.1 安装/打包

1. **安装路径**：`installer\BookShelf.iss` 第 17 行 `DefaultDirName={localappdata}\Programs\BookShelf`，第 20 行 `PrivilegesRequired=lowest`。改 `{autopf}\BookShelf` 必须同时 `PrivilegesRequired=admin`，否则会写不进去。
   - 风险：已装的用户升级时 `AppId` 不变 → 会识别为同一产品，但目录从 LocalAppData 换到 Program Files，**旧目录会残留**。建议装完提示"已迁移到 C:\Program Files\BookShelf，可手动删除旧目录"，或在 `[Code]` 里做一次旧目录清理询问。
2. **Finish 页没有启动勾选**：iss 里没有 `[Run]` 段。加：
   ```ini
   [Run]
   Filename: "{app}\BookShelf.exe"; Description: "启动 书格 BookShelf"; Flags: nowait postinstall skipifsilent
   ```
3. **exe 属性**：`FileDescription` 已改成「书格 BookShelf」（本轮已提交），要 1.1.6 打包才生效。

### 3.2 书库界面（截图 1）

4. 顶部两行（菜单栏 + 工具条），5 个按钮同权重平铺 —— 用户不知道"扫描新书 → 识别 → 预览 → 执行"是流程，视觉上没有顺序感。
5. 品牌区只有 `BS` 方块，中文名和英文名割裂（标题栏是「书格」，页面里是「书格 · 书库管理」）。
6. ISBN 列显示成 `9787539949...`，宽度不够，且无法复制全文。
7. 表格没有"阅读进度/文件大小/添加时间"列，排序能力只有默认。
8. 行内无封面缩略图，扫一眼分不出书。
9. 底部状态栏塞了书库路径 + 数据目录 + "数据库 v5"，信息噪音大，真正该显示的"已显示 200 / 1872"却在表格底部。
10. 没有批量操作入口（截图里勾选框存在但选了之后无反应）。
11. 「设置」在菜单栏和工具条右侧各一个，重复。

### 3.3 阅读界面（截图 2、3）

12. 窗口标题过长：`情绪操控术：走出困境的心理策略·封面` 被截断，应只显示书名 + 章节。
13. 顶栏把"封面"当成章节名显示（`…·封面`），因为 location 的 title 取的是当前页标题，语义不对。
14. 底栏信息重复：左边 `1/324`，右边 `本章剩余 — 23:40`，再加上 `23` 页码输入框，三处都在说过进度。
15. 左侧目录三栏（目录/笔记/书签）在 1362 宽时拥挤，条目文字被截成"2 版权页 ~"这种。
16. 设置面板（Aa）里"字重 400"是个输入框，但外面还有个"改动即时生效"提示，交互冗余。
17. 缺少"双页摊开"（R2 仍未落地，`prefs_columns` 还是单栏/双栏语义）。
18. 夜间模式缺失（截图只有米黄纸面一套）。

### 3.4 与 Readest 的差距（截图 4）

19. Readest 的阅读页：顶栏只有 4 个图标 + 一个 `?`，其余收进菜单；你现在的顶栏 8 个图标，密度偏高。
20. Readest 目录条目带页码右对齐、当前章节有整行高亮块；你的只有左侧细条。
21. Readest 底部进度条是"墨点式"长条 + 右侧 `20 / 318`；你的滑块太细、信息分三处。

### 8.1 封面卡（重点优化，替代现在的「小封面 + 书名 + 作者 + 圆 i」四件套）

| 层 | 内容 | 规格 |
|---|---|---|
| 书封 | 56×78，左侧书脊阴影 + 内描边 + 外投影，右上角朱红印章块 | `border-radius:5px 7px 7px 5px`，阴影 `0 6px 14px rgba(40,35,25,.26)` |
| 书名 | 霞鹜文楷 14.5px，单行省略 | `white-space:nowrap; text-overflow:ellipsis` |
| 作者行 | 11.5px 灰，出版社前加 2px 圆点分隔 | `马伯庸 · 湖南文艺出版社` |
| 进度 | 「在读」标签 + 3px 进度条 + 百分比 | bar 撑满剩余宽度，`7%` 右对齐等宽数字 |

- 左栏 288px；顶部 3 个图标（返回书库 / 书内搜索 / 目录）；`目录 / 笔记 / 书签` 三页签。

- 顶栏 46px：侧栏开关 + 章节名 + 书名（次要灰）+ 右侧 5 图标（书签/搜索/Aa/笔记/更多）。

- 高亮：改成"荧光笔"式（文字下半 38% 上色），不再整块铺色，避免盖住字；**高亮色定 4 色**（`#CFE3F3` 蓝 / `#F5D9A8` 琥珀 / `#D8E8C2` 绿 / `#ECCFD8` 粉）。
