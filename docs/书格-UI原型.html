第三章

人间常有些散仙野妖，受了冤屈无处申诉，要来天庭击鼓鸣冤。玉帝有好生之德，只是这冒失之徒若无凭无据，便先受一顿天雷，再打入轮回。

李长庚原本还想辩驳一句，被这雷霆震得缩了缩脖子，只得把话咽了回去。他抬头看看左右，众仙个个垂目不语，仿佛方才什么都没听见。

太白金星点点头，转身出殿，脚下云路走着走着，忽然听见身后有人喊他名字。他回头一看，原来是个小猴儿，正抱着一卷竹简追上来。

“小猴子总算等到一位管事的人，哪敢怠慢，快嘴快舌把自己的事情一发说了。”
