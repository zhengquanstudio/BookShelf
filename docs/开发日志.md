## 2026-11-27 · R3b 编辑元数据

### 实现记录

- 详情浮层新增编辑模式：书名、作者、出版社、出版日期、页数、语言、ISBN、系列、标签九个输入框，进入时自动带入当前值；底部为「取消 / 保存并同步到书库」，并在上方显示编辑提示。
- 校验顺序：书名非空 → ISBN 通过 `app/core/isbn.py` 的 10/13 位校验 → 页数必须为正整数；不通过时保留编辑态并显示具体原因，不写库。
- 保存链路：`MetadataService.save_manual` 写元数据与作者/系列 → 补充页数、清空作者与系列时的字段处理 → `LibraryService.set_tags` 写标签 → `OrganizeService` 单本 `move` 归档（`plan_for_book` 计算路径，同一路径直接跳过）。
- 移动文件前会读取快照（书籍字段、标签）；移动失败时按快照回滚字段、标签与文件路径，并在浮层显示原始失败原因（如“文件被占用”），不会只提示“保存失败”。
- 归档时把 `PreviewRow.action` 设为 `move`，`library_items` 记录为 move，便于后续撤销/审计。
- 保存成功后刷新阅读器书名/作者/封面、窗口标题、详情字段与路径，并通过 `book_changed` 通知主窗口刷新书架；文件位置改变且 WebEngine 启用时，按已保存进度重新载入。
- 未设置 `library_root` 时只写库不移动文件，浮层明确提示“文件未移动”，避免误以为已归档。
- 离屏 1440×900 渲染编辑态，九个输入框、提示与操作按钮均在 404px 浮层内完整显示，无重叠。
