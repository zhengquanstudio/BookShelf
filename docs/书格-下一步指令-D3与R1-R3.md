## 1. D3 · prefs 键（半天，先做这个）

**为什么先做**：R1–R5 所有界面控件都要读写这些键，键不定下来，后面每个控件都要返工。

### 1.1 `reader_container.py::_reader_prefs()` 追加（在现有 `"column_count"` 前后插入）

```python
"page_mode": "spread" if str(data.get("page_mode")) == "spread" else "single",
"page_width": min(900, max(420, _as_int(data.get("page_width"), 560))),
"disable_double_click": _as_bool(data.get("disable_double_click"), False),
"auto_turn_sec": min(120, max(0, _as_int(data.get("auto_turn_sec"), 0))),   # 0 = 关
"reading_ruler": _as_bool(data.get("reading_ruler"), False),
"mask_top": _as_bool(data.get("mask_top"), True),
"show_clock": _as_bool(data.get("show_clock"), True),

"highlight_colors": _highlight_colors(data.get("highlight_colors")),       # 见 1.2
"turn_anim": str(data.get("turn_anim") or "flip") if str(data.get("turn_anim")) in {"instant","push","flip"} else "flip",
```

### 1.2 高亮五色校验函数（放同文件模块级）

```python
_HL_DEFAULT = ["#f2c14e", "#d99c98", "#9cc39a", "#8fb3d9", "#b6a4d9"]

def _highlight_colors(raw):
    """只接受 #rrggbb，长度固定 5，非法项回退默认值"""
    if not isinstance(raw, (list, tuple)):
        return list(_HL_DEFAULT)
    out = list(_HL_DEFAULT)
    for i, v in enumerate(list(raw)[:5]):
        s = str(v).strip().lower()
        if _HEX_COLOR.match(s):
            out[i] = s
    return out
```

### 1.3 设置持久化

- 沿用现有 `_update_prefs(**kwargs)` 写入 `settings` 表（键 `reader_prefs`，JSON）。
- **迁移兼容**：老用户存的是 `column_count: 2`（旧"双栏"），升级后应映射为 `page_mode="spread"` 一次（写一个 `settings` 里 `reader_prefs_migrated_v5=1` 的标记，别每次开机都跑）。

### 1.4 测试（`tests/test_reader_prefs.py` 追加 4 个用例）

1. 空库 → 默认值：`page_mode=="single"`、`page_width==560`、`auto_turn_sec==0`、五色等于默认；
2. 传 `page_mode="spread"`、`page_width=1200` → 夹到 `900`；
3. 传 `highlight_colors=["#ABC","#f2c14e","xxx"]` → `["#9cc39a"... ]` 前两项非法的位置回落默认、合法项保留（注意 `#ABC` 三位简写在 `_HEX_COLOR` 下是否合法，按现有正则结果断言）；

## 2. R2 · 单页 / 双页（这是当前最显眼的错误）

现状：下拉写着"单栏/双栏"，`reader.js` 用 `max-column-count=2` 在一页里分两栏 —— **语义错**。要的是"单页展示" vs "双页摊开（像书）"。

### 2.1 控件（`reader_container.py:1043-1047`）

```python
self.prefs_columns = QComboBox()
self.prefs_columns.addItem("单页", "single")
self.prefs_columns.addItem("双页（摊开）", "spread")
...
layout.addLayout(self._prefs_row("展示方式", self.prefs_columns))
```
`_on_columns_changed` 改为 `_update_prefs(page_mode=self.prefs_columns.currentData())`；`_sync_prefs_widgets` 用 `_set_combo_data(self.prefs_columns, prefs["page_mode"])`。

### 2.2 渲染（**不要真拼两个 `#paper`**）

`reader.js`：

```js
const spread = prefs.page_mode === "spread" && canSpread();   // canSpread: 视口宽 >= 2*(page_width+边距)
renderer.setAttribute("max-column-count", spread ? "2" : "1");
paper.dataset.pageMode = spread ? "spread" : "single";
paper.style.setProperty("--page-max", prefs.page_width + "px");
```

`reader.css` 追加：

```css
#paper[data-page-mode="spread"]{ max-width: min(100%, calc(var(--page-max) * 2)); }
#paper[data-page-mode="spread"]::after{
  content:""; position:absolute; top:0; bottom:0; left:50%; width:28px; transform:translateX(-50%);
  pointer-events:none; z-index:2;
  background:linear-gradient(90deg, transparent, rgba(90,72,44,.16) 45%, rgba(90,72,44,.16) 55%, transparent);
}
```

- `view-transition-name: reader-sheet`（`reader.css` 约 :151）当前**无条件**挂 `#paper`，摊开时会造成双影 → 加上 `#paper[data-page-mode="spread"]{ view-transition-name: none; }`；
- 页码/进度：`spread` 下底栏显示 `16–17`，单页显示 `16`；
- 窗口变窄：监听 resize，低于阈值自动回落 `single` 并把"双页"选项置灰（提示"窗口太窄"），但**不改用户存的 prefs**（只是临时降级）。

### 2.3 `fitPaper` 要跟着改

现有 `fitPaper/scheduleFitPaper`（`reader.js` 约 :334/:344）只按单页宽度算。改成：`availableWidth = stage.clientWidth - 2*hPadding`；`pageMax = spread ? min(page_width, availableWidth/2) : min(page_width, availableWidth)`；两者共用同一套 padding，别写两份。

**R2 验收**：切双页能看出"左右两页 + 中缝阴影 + 两页各印页码"；把窗口拖到 900px 宽自动回单页且不报错；翻页时两页同步动，无重影。

## 4. R3 · 详情浮层（可编辑元数据 + 双路径）

这是你这次最想要的功能，但**别一次做完**，拆三步提交：

**R3a 只读浮层**（先出形）
- 宽 404，锚在 `i` 左下；封面 96×134、书名、`作者 · 年份 · 出版社`、标签行；
- 元数据 9 行：语言 / 页数 / 出版日期 / ISBN / 格式（含 DRM/大小）/ 系列 / 阅读进度 / **数据文件路径** / **归档路径**；路径过长中间省略，hover tooltip 全文，右侧「📂 打开文件夹」「⟲ 按模板重算」；
- 简介 4 行截断 + 展开；
- 动作两行（主 6 + 次 3），`翻译` 用虚线置灰。

**R3b 编辑模式**
- 9 个输入框（书名/作者/出版社/出版日期/页数/语言/ISBN/系列/标签），校验：书名非空、ISBN 走 `app/core/isbn.py`、页数整数；
- 保存链路（顺序不能错）：`metadata_service.save_manual` → 重算归档路径（`naming.py`）→ 单本 `organize_service` 移动（记 undo）→ 刷新书架行 + 顶栏 + toast；
- 失败必须**逐步回滚**并显示具体原因（文件被占用 / 无写权限 / 路径非法）。

**R3c 回写 OPF**（最后做，风险最高）
- 先 `xxx.epub.bak` 备份 → 解压改 `content.opf` 的 `dc:title/creator/publisher/date/language/identifier` → 按原条目顺序与原压缩方式重新打包 → 原子替换；
- 失败保留 `.bak` 并在浮层底部说明"OPF 未写入，已保留备份"；
- PDF/MOBI/AZW3 不支持回写：只写库 + 改名，"恢复内嵌"置灰。

**R3 验收**：改书名后 ① 顶栏变、② 书架行变、③ 磁盘上的 `.epub` 解压出的 `content.opf` 变、④ 重开阅读器封面/标题正确；非法 ISBN 拒绝保存并说明原因。

### 5.2 已加的 CI（本轮新增文件）

- `.github/workflows/ci.yml`：push/PR 到 `main` 时，Windows runner 跑 `pip install -r requirements.txt` + `pytest tests -q` + `_audit/font_check.py`（字体必须真加载）。
- `.github/workflows/release.yml`：**push `v*` 标签**时自动建 venv → 跑测试 → 装 Inno Setup → `tools/build.ps1` → 上传 artifact → `gh release create` 把 `BookShelf-Setup-<版本>.exe` 和 `checksums.txt` 挂到 Release。

> 注意：`tools/build.ps1` 里硬编码了 `$Root\.venv\Scripts\python.exe`，CI 已按这个路径建 venv，不要把脚本改成别的路径，否则本地和 CI 两套逻辑。

### 5.3 以后每发一版的固定动作（4 步）

1. 改版本：`app/config.py` 的 `APP_VERSION` → 例如 `1.2.0`；同步 `CHANGELOG.md` 顶部加一段（日期 + 变更点）；
2. 本地验证：`python -m pytest tests -q` 全绿；`tools\build.ps1` 能在本地出包（可选，CI 也会出）；
3. 提交并打标签：
   ```powershell
   git add -A
   git commit -m "release: 1.2.0"
   git tag v1.2.0
   git push origin main
   git push origin v1.2.0
   ```
4. 等 Actions 的 `release` 跑完（10–15 分钟），到 https://github.com/zhengquanstudio/BookShelf/releases 确认 `BookShelf-Setup-1.2.0.exe` 已挂上；把 `checksums.txt` 里的 SHA256 贴到 Release 说明里。

国内网络下 `git push` 走 SSH 22 端口偶发超时，可临时切 443：
```powershell
ssh -T -p 443 git@ssh.github.com          # 已验证可用（Hi zhengquanstudio!）
git remote set-url origin ssh://git@ssh.github.com:443/zhengquanstudio/BookShelf.git
```
